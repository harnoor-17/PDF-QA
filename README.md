# Keya PDF Chatbot

A fully functional LLM-based chatbot that allows you to upload a PDF and ask context-aware questions about it using Google Gemini.

## Features

- Upload PDF files via web interface
- Process and chunk text from PDF using sentence-transformers
- Embed and index content using FAISS
- Ask questions with Gemini 1.5 Pro
- Flask + Tailwind + HTML UI integration

## Usage

1. Clone the repo and install dependencies
2. Add your API key in `.env`
3. Run `python app.py`
4. Open `http://127.0.0.1:5000` in your browser
